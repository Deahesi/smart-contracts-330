# NFT-330 — смарт-контракты

Архивный проект 2022 года: смарт-контракты для выпуска и продажи NFT стандарта ERC-1155. Код сохранён как историческая версия проекта.

## Что внутри

- `contracts/NFT330.sol` — выпуск NFT владельцем контракта, включая пакетный выпуск. Адреса JSON-метаданных формируются по ID токена и ведут на Amazon S3.
- `contracts/NftTrader.sol` (`NftTrader330`) — продажа NFT одной коллекции с комиссией сервиса и роялти автору. Объявления создаёт владелец контракта, продавцы могут менять цену.
- `contracts/GoodNftTrader.sol` (`NftTrader`) — вариант торгового контракта для разных коллекций ERC-1155 с комиссией сервиса.
- `contracts/SaleNFT.sol` — прототип продажи с внутренним учётом балансов и количества токенов, без фактической передачи ERC-1155.
- `contracts/Test721.sol` (`ReBrand`) — экспериментальный ERC-1155 контракт со встроенной продажей и логикой вознаграждений в ERC-20. Несмотря на имя файла, это не ERC-721; настройка адреса ERC-20 в конструкторе закомментирована.
- `migrations/` — скрипты развёртывания Truffle.

## Технологии

Solidity, OpenZeppelin Contracts 4.x и Truffle. В `truffle-config.js` указан компилятор Solidity 0.8.10 и настройки локальной сети, BNB Smart Chain и её тестовой сети.

## Компиляция

Нужны Node.js, npm и установленный Truffle.

```sh
npm install
truffle compile
```

## Состояние архива

В коде остались экспериментальные и незавершённые части. В частности, `migrations/2_nft330_migration.js` ссылается на отсутствующий контракт `MyNft`, поэтому перед развёртыванием миграцию нужно исправить. Некоторые изменения объявлений в торговых контрактах выполняются только в памяти и не сохраняются в состоянии контракта.

Для повторного использования потребуются проверка логики, тестирование и актуализация зависимостей и сетевых настроек.
